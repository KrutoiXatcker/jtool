# jtool

`jtool` — расширяемый каркас консольной утилиты на C++ для Linux.

## О проекте

Проект разрабатывается инженером по информационной безопасности и предназначен
для создания единого набора инструментов, используемых при диагностике,
администрировании и решении задач информационной безопасности.

На данном этапе `jtool` представляет собой простой программный каркас. Он
предоставляет базовое ядро, регистрацию команд и структуру для подключения
новых функциональных модулей.

Архитектура проекта рассчитана на постепенное расширение. Новые возможности
можно добавлять независимо друг от друга, не изменяя основную логику программы.
В перспективе `jtool` должен превратиться в универсальный «швейцарский нож» для
инженера по информационной безопасности.

## Основные принципы

- простое и независимое ядро;
- разделение функциональности на модули;
- автоматическое подключение исходных файлов при сборке;
- отсутствие необходимости изменять ядро при добавлении команд;
- поддержка команд с любым количеством уровней;
- минимальное количество внешних зависимостей;
- возможность постепенно развивать проект без изменения его общей структуры.

## Структура

```text
jtool/
├── core/       # Ядро и маршрутизация команд
├── modules/    # Функциональные модули
├── Makefile    # Сборка проекта
└── README.md
```

Ядро обрабатывает аргументы командной строки, находит зарегистрированную
команду и передаёт управление соответствующему модулю. Прикладная логика
размещается только в папке `modules/`.

## Сборка

Для сборки необходимы компилятор с поддержкой C++17 и `make`:

```bash
make
```

После сборки будет создан исполняемый файл `jtool`.

Для очистки результата сборки:

```bash
make clean
```

## Команды

Каркас поддерживает команды произвольной глубины, например:

```bash
jtool system status
jtool docker container start
jtool network tcp scan
```

Показать список зарегистрированных команд:

```bash
./jtool --help
```

Показать справку для отдельного раздела:

```bash
./jtool help <command>
```

## Добавление модуля

Новый модуль создаётся отдельной папкой внутри `modules/`:

```text
modules/
└── module_name/
    └── module.cpp
```

Команда регистрируется с помощью объекта `jtool::Command`:

```cpp
#include "jtool.hpp"

#include <iostream>

namespace {

int handler(const jtool::Arguments &arguments) {
    std::cout << "Command executed\n";
    return 0;
}

const jtool::Command command(
    {"module", "action", "run"},
    "command description",
    handler);

} // namespace
```

После повторного выполнения `make` команда будет доступна через общий
исполняемый файл:

```bash
./jtool module action run
```

Все значения, указанные после зарегистрированного пути команды, передаются в
обработчик через `jtool::Arguments`.

## Статус

Проект является основой для дальнейшей разработки. Конкретный набор модулей и
инструментов будет формироваться по мере развития `jtool`, при этом структура
ядра и общий принцип расширения останутся неизменными.
